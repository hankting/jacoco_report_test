# Jarvis Subgraph
Powered by Netflix DGS GraphQL and Spring boot

## Getting Started
1. Clone the repository
2. The project is using OpenJDK 21. Make sure you have it installed in your machine `brew install --cask temurin@21`
3. Compile the project using `./gradlew clean build`
4. Run the project using `./gradlew bootRun`
5. Open the browser and navigate to `http://localhost:8081/graphiql` to access the GraphQL playground (Every subgraph has it's own port)
